# 架构一页 · dsh-butler-engine

一次读完：这个包里有什么、各自管什么、谁读写谁。

## 1. 一次 tick 的路径

```
butler-tickd（常驻循环，默认 15s 一拍）
  ├─ 读开关        autonomy-modules.mjs   ← <home>/butler-autonomy.json#jobs
  ├─ 选到期作业     JOBS（源码常量）+ 间隔 / 每天 / 每周 / 时段窗四种形态
  ├─ 拿单实例锁     store.mjs#acquireTickLock  ← 锁名由 butler-locks.mjs 决定（按作业登记）
  ├─ spawn 子进程   作业脚本（不随本包发布）
  ├─ 记账           state.json（心跳 / 每作业最近结果 / 预算）+ fail-trace（失败留痕）
  └─ 告警走         alert.mjs（stderr + <home>/butler-alert.log，不依赖别的组件）
```

同一条作业如果还有别的触发源（手动、计划任务），只要用同一个锁名（`lockNameFor(jobId)`），
撞上就"本轮让路"，不会两份同时写同一个状态文件。

## 2. 模块职责

| 模块 | 管什么 |
|---|---|
| `dsh-butler/butler-tickd.mjs` | 入口：作业表 `JOBS`、调度循环、CLI（`--list/--status/--once/--ensure/--stop`） |
| `dsh-butler/lib/butler-locks.mjs` | **锁注册表**（单一数据源）：作业 → 锁名 / TTL / 关键写面 / 交接窗口让路 |
| `dsh-butler/lib/autonomy-modules.mjs` | 模块级与作业级开关矩阵；`declaredJobDefault()` = 「配置里没写时该开还是关」 |
| `dsh-butler/lib/autonomy.mjs` | 全局自治开关（裸跑期的"开关清单"唯一入口：P3 自动动作 / 自愈 / 等） |
| `dsh-butler/lib/autonomy-state.mjs` | 自治**降档**开关（全局唯一入口） |
| `dsh-butler/lib/authorize-compose.mjs` | 授权合成 `min(对象 S 档, actor 矩阵, 动作 L 级)`：取最保守者 |
| `dsh-butler/lib/store.mjs` | **状态文件唯一入口**：原子写、读-改-写锁、tick 单实例锁、jsonl 追加 |
| `dsh-butler/lib/state-paths.mjs` | 状态名解析与 legacy ↔ 新名迁移（改名期两边都认） |
| `dsh-butler/lib/state-exceptions.mjs` | 状态改名迁移的**例外白名单**（唯一真源） |
| `dsh-butler/lib/dual-write.mjs` | 双写器：迁移期唯一写入口（同一份字节写两个名字 + 失败记账） |
| `dsh-butler/lib/paths.mjs` | **路径单点**：`~/.dsh` 根、常用子路径、`realpath` 归一 |
| `dsh-butler/lib/alert.mjs` | 告警通道（stderr + 日志），故意不 import 任何兄弟组件，避免"自己掉队时自己喊不出" |
| `dsh-butler/lib/audit.mjs` | **哈希链审计**：上一条的 hash 进下一条，改中间一条后面全对不上 |
| `dsh-butler/lib/audit-lock.mjs` | 审计追加的**跨进程写锁**（两个进程同时 append 会让哈希链分叉） |
| `dsh-butler/lib/audit-chain-watch.mjs` | 审计链尾部巡检 + 「新断链」告警（同一断点只报一次） |
| `dsh-butler/lib/version.mjs` | 组件版本真值（实体 vs 声明 vs 兜底），`pluginEntityRoots()` |
| `dsh-butler/lib/version-disposition.mjs` | 版本漂移时给两条候选处置，只给建议、不自己执行 |
| `dsh-butler/lib/handoff-version-gate.mjs` | 交接窗口检测（窗口内不许起会打断对方的事） |
| `dsh-butler/lib/monitor-registry.mjs` | 注册制监视器实体：每个被管对象一条登记（探针 / 期望值 / S 档 / 负责人） |
| `dsh-butler/lib/slo-tail.mjs` | 尾部 SLI 的只读采集器（内存 RSS 等，候选态） |
| `dsh-butler/lib/tickd-metrics.mjs` | tick 观测口径的**单一真源**：指标命名前缀 + 各作业耗时预算 |
| `dsh-butler/lib/tickd-fail-trace.mjs` | 子进程失败原因留痕（`exit code 1` 之外还要留住它到底报了什么） |
| `dsh-butler/lib/product.mjs` | 产品版本常量（唯一硬编码点，避免 store ↔ version 成环） |
| `lib/production-guard.mjs` | **生产树守卫**：判断某个路径是不是落在"生产树"里（逻辑路径 + realpath 双面比） |
| `lib/bypass-ledger.mjs` | 绕过台账（门误报后被绕过，也要看得见） |
| `lib/deploy-guard.mjs` | 部署守卫（跨目录引用 / 逃逸判定） |
| `lib/dsh-home.mjs` | `~/.dsh` 与工作区根解析（测试实例可整体重定向） |

## 4. 三条不变量

1. **关是显式的，开也是显式的**：源码里不写 `enabled:false`（那等于硬禁用、`job on` 也打不开）；"默认关"只能靠 `defaultWhenUnset:'off'` 或本包的缺键即关。
2. **状态文件的写一律过 `store.mjs`**：原子写 + 锁，不许各脚本自己 `writeFileSync`。
3. **锁名只从注册表来**：任何新作业都必须先在 `butler-locks.mjs` 登记，否则它就是一个不受单实例保护的触发器。

## 5. 日报 / 巡检工具（0.2.0）

六个入口都是「读现状 → 出结论 → 不动手」：

| 入口 | 读什么 | 产出 | 写面 |
|---|---|---|---|
| `steward.mjs` | 看板 / 进度登记 / 产物目录 / 待办 | 一份日报（`--json` 给机器） | 报告文件 |
| `steward-threads.mjs` | thread 数据文件 | 建串 / 挂卡 / 订阅 / 扇出 | thread 数据文件 |
| `steward-advice.mjs` | 卡 + 依据 | 四段建议（现象 / 判断 / 动作 / 依据） | 只读 |
| `failure-classify.mjs` | 会话日志 + 卡账本 | 五类失败统计 + 草稿 | 草稿（`--apply` 才写） |
| `progress-status.mjs` | 进度登记表 | 一页进度表 | 只读 |
| `stall-nudge.mjs` | 看板 / 交接档 | 停滞候选 + Top N 提醒 | 状态文件 + 报告 + 注入点推送 |

**通知出口只有一个**：`lib/notify.mjs`。

```
业务侧（steward / stall-nudge / watch-notify）
   └─ notify({ level, title, body, dedupeKey, channel })
        ├─ 开关：<home>/butler-alert.json#channels.alert（默认关）
        ├─ 去重：同一 dedupeKey 同一本地日一次（<home>/butler-notify-dedupe.json）
        └─ 实现：宿主 setNotifier(fn) 注入；没注入 = console + no-op（回 no-channel，不假装发出）
```

包里**没有**任何具体通道实现（企业微信 / 微信 / 语音都不在）——这是有意的：
通道绑定账号与凭证，只能由使用者自己接。
